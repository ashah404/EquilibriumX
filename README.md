

# Equilibrium X 💎
> **پلتفرم هوشمند برای مدیریت، تبدیل و توزیع بار (Load Balancing) کانفیگ‌های VLESS به همراه تست پینگ زنده.**


---
<div dir="rtl">
**Equilibrium X** یک جعبه‌ابزار همه‌کاره و قدرتمند دسکتاپ بر پایه **Electron** و **React** است که به شما امکان می‌دهد کانفیگ‌های پراکنده و تک‌مسیر VLESS خود را به راحتی ادغام کرده و آن‌ها را در قالب یک لود بالانسر (توزیع‌کننده بار) فوق‌العاده پایدار بر روی هسته قدرتمند **Xray-core** سوار کنید. علاوه بر این، ابزارهای خودکار ساخت پیکربندی‌های ابری بر روی Netlify، Vercel و GitHub Pages را به صورت یکپارچه در اختیارتان قرار می‌دهد.
</div>

## 📥 راهنمای استفاده برای کاربران عادی (No-Code User Guide)
اگر توسعه‌دهنده نیستید و صرفاً می‌خواهید از برنامه استفاده کنید، نیازی به نصب هیچ پیش‌نیازی (مثل Node.js یا Git) یا تایپ دستورات ترمینال ندارید. کافیست مراحل زیر را دنبال کنید:

1. به بخش **[Releases](https://github.com/ashah404) (انتشارها)** در ستون سمت راست همین مخزن گیت‌هاب بروید.
2. بر اساس نیاز خود، یکی از دو نسخه زیر را دانلود کنید:
   * **نسخه پرتابل (Portable):** فایل `Equilibrium X 1.0.0.exe`  
     *(بدون نیاز به نصب؛ کافیست پس از دانلود روی آن دوبار کلیک کنید تا برنامه فوراً باز شود. عالی برای اجرا از روی فلش مموری یا استفاده سریع).*
   * **نسخه نصب‌کننده (Setup):** فایل `Equilibrium X Setup 1.0.0.exe`  
     *(فایل نصب استاندارد ویندوز که میانبر برنامه را در دسکتاپ و منوی استارت شما ایجاد می‌کند).*
3. **اولین اجرا:** در اولین اجرا، برنامه به طور هوشمند و خودکار آخرین نسخه رسمی هسته اجرای شبکه یعنی **Xray-core** را متناسب با سیستم‌عامل شما دانلود و در پوشه امن AppData پیکربندی می‌کند. کل این فرآیند در پس‌زمینه اتفاق می‌افتد و برنامه بدون هیچ تنظیمات پیچیده‌ای آماده استفاده خواهد بود.

## ⚡ قابلیت‌های کلیدی (Key Features)

* **⚖️ لود بالانسر هوشمند و بومی:** تبدیل دسته‌ای کانفیگ‌های VLESS به ساختار لود بالانسر پیشرفته Xray با الگوریتم‌های توزیع بار کارآمد نظیر `leastPing` (انتخاب سرور بر اساس کمترین تاخیر)، `roundRobin` (گردشی زنده) و `random` (تصادفی).
* **🧪 تست پینگ چند رشته‌ای واقعی (Multi-threaded Tester):** سنجش دقیق تاخیر سرورها با اجرای موقت و ایزوله آن‌ها بر روی پورت‌های تصادفی و فرستادن درخواست واقعی به Google 204 (دقیقاً مشابه منطق تست برنامه v2rayN).
* **🌐 ابزارسازهای ابری یکپارچه:** فرم‌ها و قالب‌های اختصاصی برای ساخت خودکار و استقرار سریع ساب دامنه/ترافیک روی بسترهای رایگان ابری از جمله **Netlify Workers**، **Vercel** و **GitHub Pages**.
* **✨ رابط کاربری پریمیوم (Glassmorphism UI):** طراحی بصری تیره و فوق‌العاده مدرن با افکت‌های نئونی، شیشه‌ای و انیمیشن‌های نرم ورودی بدون سربار روی منابع سیستم.
* **🛡️ اجرای بدون نیاز به دسترسی ادمین:** دانلود و اجرای خودکار هسته Xray در مسیر امن کاربر (AppData) جهت جلوگیری از خطاهای دسترسی و فایل‌های سیستمی ویندوز.

## 🚀 راهنمای توسعه‌دهندگان (Developer Guide)
اگر می‌خواهید روی توسعه پروژه کار کنید یا شخصاً آن را از روی سورس کد کامپایل کنید، مراحل زیر را دنبال کنید:

### پیش‌نیازها
* [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر)
* ابزار مدیریت پکیج `npm`

### ۱. نصب وابستگی‌ها
مخزن را کلون کنید، وارد پوشه پروژه شوید و وابستگی‌های مورد نیاز را نصب کنید:

</div>

<div dir="ltr">

```bash
git clone https://github.com/ashah404.git
cd "Equilibrium X"
npm install
```

</div>

<div dir="rtl">

### ۲. اجرای پروژه در محیط توسعه (Local Development)
برای اجرای هم‌زمان سرور محلی فرانت‌اند (Vite Dev Server) و شبیه‌ساز پنجره دسکتاپ الکترون (Electron Wrapper):

</div>

<div dir="ltr">

```bash
npm run dev:desktop
```

</div>

<div dir="rtl">

*هر تغییری در کدهای فرانت‌اند به صورت زنده و با استفاده از Hot Module Replacement در پنجره دسکتاپ منعکس می‌شود.*

### ۳. کامپایل و بسته‌بندی نهایی (Build & Pack)
برای تولید فایل‌های اجرایی نهایی ویندوز (شامل پرتابل و نصبی):

</div>

<div dir="ltr">

```bash
npm run pack:desktop
```

</div>

<div dir="rtl">

پس از اتمام موفقیت‌آمیز بیلد، خروجی‌ها در پوشه `release/` در ریشه پروژه قرار خواهند گرفت:
* `release/Equilibrium X 1.0.0.exe` (نسخه پرتابل بدون نیاز به نصب)
* `release/Equilibrium X Setup 1.0.0.exe` (نسخه نصب‌کننده استاندارد ویندوز)
